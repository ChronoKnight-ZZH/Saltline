# M1 骨架修改方案

> 依据：`Saltline天气时间系统改造.md` 第 6 章 M1、`DEVELOPMENT.md`、`WIKI.md`。  
> M1 只建立**环境状态中枢 + 预设 + 渲染/地面/材质写入通路 + 运行时装配 + URL 参数**，不接入敌人感知、武器扩散、HUD 标记、直升机、闪电。M2–M4 再消费 `perception` 与子系统。

---

## 1. M1 目标与边界

### 1.1 目标

固定 seed 下可复现地选择/随机 `timeOfDay × weather`，并让以下表现立即生效、每帧平滑：

- 太阳方向/颜色/强度、天空颜色、PMREM 环境贴图
- 雾颜色/密度、曝光
- 地面雨量、全局湿度 `mats.uniforms.wet`
- 武器视图模型雨水 `weapon.setWetness`

同时暴露 `environment.perception` 与 `environment.visibility`，供 M2 玩法层读取。

### 1.2 明确不做

| 项 | 里程碑 |
|---|---|
| `enemies/walker/drone` 视觉/听觉接入 | M2 |
| `weapon.spread` 乘 `perception.spreadScale` | M2 |
| 设置面板“时间/天气”下拉 | M2 |
| `world/helicopter.js`、`effects/lightning.js` | M3/M4 |
| 闪电能见度脉冲、暴露扫描、HUD 标记 | M3/M4 |
| `backdrop/level` 灯光 `setLights`、雨幕粒子降级、音频天气层 | M5 |
| `ground.setReflections` 按天气驱动 | M5 |

M1 的 `environment` 中 `helicopter/lightning` 字段保持 `null`，`_onLightningFlash/_updateHelicopter` 先留空实现，M3/M4 再填。

## 2. 前置决策（M1 开工前确认）

| 决策点 | 推荐 | 理由 |
|---|---|---|
| `core/environment.js` 的分层 | 保持 `core/`，在 WIKI 3.1 增加“L1.5 环境协调器”例外：允许依赖 L2 的 **setter 接口**（`render.setSun/setFog/setExposure/rebakeEnvironment`、`ground.setRain`、`mats.uniforms.wet`），禁止读取玩法状态 | 改造文档已定 `core/environment.js`；它本质是“状态中枢 + 表现写入”，不是纯 L1 工具 |
| 环境随机源 | **独立派生 seed**，不推进 `context.rng`：`createRandom((seed ^ 0x9E3779B9) >>> 0)` | 若用 `context.rng.fork()`，会推进父随机源，改变 `fx/audio/weapon` 等后续系统的随机序列，破坏现有固定 seed 回归 |
| `?shot=1` / `?bench=1` 下的环境 | 不随机，使用 `DEFAULT_ENV`（建议 `dawn/clear` 或与现有 `SUN_LIGHT/SKY_COLORS` 最接近的预设） | 截图回归必须稳定；原版无时间天气概念，默认预设应尽量匹配原视觉 |
| 原版是否有 `scene.fog` | 先检查 `renderer.js`；若没有，`setFog` 创建 `FogExp2`，`FOG_K` 初始取很小值（建议使 `noon/clear` 的 `fogDensity ≤ 0.002`） | 避免 M1 就大幅改变原版画面；M6 再调参 |
| `weapon.setWetness` 与室内逻辑合并 | 保留现有 `interiorBox` 判定，改为 `wet = interior ? envWet * 0.15 : envWet` | 室内雨水影响降低，但仍保留环境湿度语义 |
| `environment` 初始化失败 | 建议加 `FALLBACKS.environment`，提供空 `update/perception/visibility` | 符合 WIKI 3.7 优雅降级；environment 依赖多系统，失败不应阻断启动 |

### 3.1 `src/core/environment-presets.js`（约 220–300 行）

**要点：**

- `TIME_PRESETS` 的基准预设（建议 `noon` 或 `dawn`）必须从 `core/config.js` 的 `SUN_LIGHT`、`SKY_COLORS` 反推，保证 `?shot=1` 默认环境视觉差异最小。
- `combine` 纯函数，不读 `context`，便于单测与调参。
- `target.fogDensity = FOG_K / target.visibility * weather.fogMul`，`target.visibility = time.visibility * weather.visibilityMul`。
- `target.lightningEnabled = weather.lightning`；`target.helicopterEnabled = timeOfDay === "midnight" && !weather.lightning`。M1 只计算不消费。
- `DEFAULT_ENV` 用于 `?shot=1` / `?bench=1` 和无参数回退（若选择不随机）。

### 3.2 `src/core/environment.js`（约 320–450 行）

**导出：**

```js
import { createRandom } from "./random.js";
import { damp, clamp } from "./math.js";
import { TIME_PRESETS, WEATHER_PRESETS, DEFAULT_ENV, combine } from "./environment-presets.js";

export function createEnvironment(context) {
  const seed = Number(context.params?.get?.("seed") || 4207);
  const rng = createRandom((seed ^ 0x9E3779B9) >>> 0);

  const state = {
    timeOfDay: DEFAULT_ENV.timeOfDay,
    weather: DEFAULT_ENV.weather,
    target: combine(DEFAULT_ENV.timeOfDay, DEFAULT_ENV.weather),
    current: null, // 首次 set 时拷贝 target 的标量
  };

  const visibility = { base: state.target.visibility, current: state.target.visibility, lightningPeak: 0, lightningT: 0 };

  const perception = {
    get visibility() { return visibility.current; },
    get visualAlert() { return 1.0; },
    get audioMask() { return state.current?.audioMask ?? state.target.audioMask; },
    get spreadScale() { return state.current?.spreadScale ?? state.target.spreadScale; },
    footstepMaskAt(pos) {
      // M1 只合并雨声；直升机 M3 接入
      return Math.min(state.current?.audioMask ?? state.target.audioMask, 0.85);
    },
  };

  function _cloneCurrent(target) {
    return {
      fogDensity: target.fogDensity,
      exposure: target.exposure,
      rainLevel: target.rainLevel,
      wetness: target.wetness,
      audioMask: target.audioMask,
      spreadScale: target.spreadScale,
    };
  }

  function _applyStatic() {
    const t = state.target;
    context.render.setSun(t.sunDir, t.sunColor, t.sunIntensity);
    context.render.setFog(t.fogColor, state.current?.fogDensity ?? t.fogDensity);
    context.render.setExposure(state.current?.exposure ?? t.exposure);
    if (context.quality?.envBake !== false) context.render.rebakeEnvironment();
    context.ground?.setRain?.(state.current?.rainLevel ?? t.rainLevel);
    if (context.mats?.uniforms?.wet) context.mats.uniforms.wet.value = state.current?.wetness ?? t.wetness;
  }

  function _pushFrame(dt) {
    const c = state.current, t = state.target;
    c.fogDensity = damp(c.fogDensity, t.fogDensity, 3, dt);
    c.exposure = damp(c.exposure, t.exposure, 3, dt);
    c.rainLevel = damp(c.rainLevel, t.rainLevel, 3, dt);
    c.wetness = damp(c.wetness, t.wetness, 3, dt);
    c.audioMask = damp(c.audioMask, t.audioMask, 4, dt);
    c.spreadScale = damp(c.spreadScale, t.spreadScale, 4, dt);

    if (visibility.lightningT > 0) {
      // M1 不会进入；M4 使用
      visibility.lightningT -= dt;
      visibility.current = visibility.lightningPeak;
    } else {
      visibility.current = damp(visibility.current, visibility.base, 3, dt);
    }

    context.render.setFog(t.fogColor, c.fogDensity);
    context.render.setExposure(c.exposure);
    context.ground?.setRain?.(c.rainLevel);
    if (context.mats?.uniforms?.wet) context.mats.uniforms.wet.value = c.wetness;
  }

  function setTimeOfDay(name) {
    if (!TIME_PRESETS[name] || name === state.timeOfDay) return;
    state.timeOfDay = name;
    state.target = combine(state.timeOfDay, state.weather);
    visibility.base = state.target.visibility;
    if (visibility.current > visibility.base) visibility.current = visibility.base;
    _applyStatic();
    context.events?.emit("environment:changed", { timeOfDay: name, weather: state.weather });
  }

  function setWeather(name) {
    if (!WEATHER_PRESETS[name] || name === state.weather) return;
    state.weather = name;
    state.target = combine(state.timeOfDay, state.weather);
    visibility.base = state.target.visibility;
    if (visibility.current > visibility.base) visibility.current = visibility.base;
    _applyStatic();
    context.events?.emit("environment:changed", { timeOfDay: state.timeOfDay, weather: name });
  }

  function set({ timeOfDay, weather }) {
    const nextTime = timeOfDay && TIME_PRESETS[timeOfDay] ? timeOfDay : state.timeOfDay;
    const nextWeather = weather && WEATHER_PRESETS[weather] ? weather : state.weather;
    if (nextTime === state.timeOfDay && nextWeather === state.weather) return;
    state.timeOfDay = nextTime;
    state.weather = nextWeather;
    state.target = combine(nextTime, nextWeather);
    visibility.base = state.target.visibility;
    if (!state.current) state.current = _cloneCurrent(state.target);
    if (visibility.current > visibility.base) visibility.current = visibility.base;
    _applyStatic();
    context.events?.emit("environment:changed", { timeOfDay: nextTime, weather: nextWeather });
  }

  function randomize() {
    const timeKeys = Object.keys(TIME_PRESETS);
    const weatherKeys = Object.keys(WEATHER_PRESETS);
    set({ timeOfDay: rng.pick(timeKeys), weather: rng.pick(weatherKeys) });
  }

  function update(dt) {
    if (!state.current) state.current = _cloneCurrent(state.target);
    _pushFrame(dt);
    // M3: context.helicopter?.update(dt);
    // M4: context.lightning?.update(dt);
  }

  // 初始化
  state.current = _cloneCurrent(state.target);
  visibility.current = visibility.base;
  _applyStatic();

  return {
    get timeOfDay() { return state.timeOfDay; },
    get weather() { return state.weather; },
    setTimeOfDay, setWeather, set, randomize, update,
    perception, visibility,
    _applyStatic, _pushFrame,
    _onLightningFlash() { /* M4 */ },
    _updateHelicopter() { /* M3 */ },
  };
}
```

**要点：**

- `_applyStatic` 负责同步重活（太阳/天空/PMREM/雾颜色/初始雨量/湿度），`_pushFrame` 每帧只写 damp 后的标量。
- 首次 `set` 前 `current` 已初始化为 target 拷贝，避免从 0 开始 damp。
- `visibility.current` 在切换时若大于新 `base`，直接钳到 `base`，避免“高能残留”跨天气。
- `perception` 的 getter 使用 `current`，M2 可直接读。
- `environment:changed` 事件 M1 可先派发，HUD/音频 M5 再消费；需登记到 WIKI 3.5。

### 4.2 `src/render/sky.js`

**检查：** `Hy(noiseTexture)` 内天空 `ShaderMaterial` 目前是否把 `SKY_COLORS` / `SUN_LIGHT` 作为常量写死。

**修改：**

1. 把 `uSkyTop`、`uSkyHorizon`、`uSunColor`、`uSunDir` 改为 `uniforms`，默认值取 `SKY_COLORS` 与 `SUN_LIGHT`。
2. 新增导出：

```js
export function applySkyPreset(sky, { skyTop, skyHorizon, sunColor, sunDir }) {
  const u = sky?.material?.uniforms;
  if (!u) return;
  u.uSkyTop?.value?.set?.(...skyTop) ?? (u.uSkyTop.value = skyTop);
  u.uSkyHorizon?.value?.set?.(...skyHorizon) ?? (u.uSkyHorizon.value = skyHorizon);
  u.uSunColor?.value?.set?.(...sunColor) ?? (u.uSunColor.value = sunColor);
  u.uSunDir?.value?.set?.(...sunDir) ?? (u.uSunDir.value = sunDir);
}
```

参数 `sunDir` 使用 `Vector3` 或数组，按 `Hy` 现有类型决定；`Vy` 烘焙时克隆材质，需确认新 uniform 在克隆中保留（Three.js `ShaderMaterial.clone()` 会复制 uniforms 值引用，必要时 `uniforms` 显式克隆）。

**验收：** `?show=render` 下天空颜色正常；`Vy` 烘焙后的 PMREM 随 `applySkyPreset` 改变。

### 4.3 `src/render/renderer.js`

**新增方法：**

```js
setSun(dir, color, intensity) {
  // dir: Vector3 或 [x,y,z]；保持与现有 SUN_LIGHT 相同的方向语义
  this.sun.position.copy(dir).multiplyScalar(SUN_DISTANCE);
  this.sun.target.position.set(0, 0, 0);
  this.sun.target.updateMatrixWorld();
  this.sun.color.set(color);
  this.sun.intensity = intensity;
  this.sunDir.copy(dir).normalize();
  applySkyPreset(this.sky, { skyTop: ..., skyHorizon: ..., sunColor: color, sunDir: this.sunDir });
  // M1 简化：切换时重拟合阴影；若现有 createRenderer 已有 refit，调用它
  this._refitShadows?.();
}

setFog(color, density) {
  if (!this.scene.fog) this.scene.fog = new THREE.FogExp2(color, density);
  this.scene.fog.color.set(color);
  this.scene.fog.density = density;
}

setExposure(v) {
  this.exposure = v;
  this.renderer.toneMappingExposure = v; // 以现有 exposure 写入路径为准
}

rebakeEnvironment() {
  if (!this.quality?.envBake) return;
  const env = Vy(this.renderer, { mesh: this.sky, material: this.sky.material, geometry: this.sky.geometry });
  this.scene.environment = env.texture;
  this.env = env.texture;
}
```

**要点：**

- `setSun` 中的 `skyTop/skyHorizon` 需要从 `TIME_PRESETS` 传入，但 `renderer` 不应 import presets。建议签名改为 `setSun({ sunDir, sunColor, sunIntensity, skyTop, skyHorizon })`，或让 environment 先调 `applySkyPreset` 再调 `setSun`。推荐：**`setSun` 只处理太阳光与 `uSunColor/uSunDir`，天空 top/horizon 由 environment 调 `render.setSkyColors(skyTop, skyHorizon)`**，避免 renderer 依赖预设结构。
- `SUN_DISTANCE` 使用现有 `SUN_LIGHT` 的距离或 `sun.position.length()`。
- 阴影重拟合：M1 可在 `setSun` 内调用现有 `Gy` 重拟合一次；若现有 `createRenderer` 没有暴露 `refit`，M1 先只更新 `sun.position/target`，阴影在 `onLevelReady` 后由现有逻辑处理，M6 再补重拟合。
- `rebakeEnvironment` 中 `Vy` 返回 `WebGLRenderTarget`，`scene.environment` 用 `.texture`。
- `low` 画质 `envBake=false` 时跳过，沿用启动时 `env`。

**验收：** 控制台 `__G.render.setExposure(0.6)` 画面变暗；`setFog` 后雾生效；`low` 下 `rebakeEnvironment()` 无操作。

**`weapon.setWetness` 合并：**

```js
// 原逻辑：根据相机是否在第一个 interiorBox 内计算 interiorWet
const interior = /* 现有判定 */;
const envWet = context.environment?.perception ? context.environment._currentWetness?.() ?? 0 : 0;

```

建议在 `environment` 增加 `get wetness() { return state.current?.wetness ?? 0; }`，避免 runtime 访问内部字段。

**URL 参数：**

```js
const timeParam = params.get("time");
const weatherParam = params.get("weather");
const fixed = params.get("shot") || params.get("bench");

if (timeParam || weatherParam) {
  environment.set({
    timeOfDay: TIME_PRESETS[timeParam] ? timeParam : undefined,
    weather: WEATHER_PRESETS[weatherParam] ? weatherParam : undefined,
  });
} else if (fixed) {
  environment.set(DEFAULT_ENV);
} else {
  environment.randomize();
}
```

## 5. 接口契约汇总

| 调用方 | 被调方 | 契约 |
|---|---|---|
| `environment._applyStatic` | `render.setSun(preset)` | 更新太阳方向/颜色/强度、天空 `uSunColor/uSunDir`；返回 void |

## 6. 预设标定建议

1. **基准预设**：先用 `noon` 或 `dawn` 匹配 `core/config.js` 的 `SUN_LIGHT`、`SKY_COLORS`，通过 `?shot=1&q=test&seed=4207&dt=0&noaudio=1&cam=...` 对比改造前后截图，确保默认环境差异可解释。
2. **`FOG_K`**：M1 初始取小值（建议 `0.02`），使 `noon/clear` 的 `fogDensity` 接近原版（若原版无雾则接近 0）。M6 按“能见度 220m 时远处目标可辨”标定。
3. **`exposure`**：`dawn/noon` 接近现有曝光；`dusk` 略低；`midnight` 更低。M1 只建通路，M6 调。
4. **`visibility`**：`dawn 180 / noon 220 / dusk 160 / midnight 90` 作为初始值；M2 接入敌人视觉后按“敌人视觉半径 ≤ 玩家能见距离”校验。

## 9. 风险与回滚

| 风险 | 缓解 |
|---|---|
| 天空 shader uniform 化破坏 PMREM 烘焙 | 先改 `Hy` 并单独验证 `?show=render`；`Vy` 克隆材质时检查 uniforms 引用 |
| 引入 `scene.fog` 改变原版视觉 | `FOG_K` 初始取小值；`?shot=1` 截图对比；必要时 `clear` 天气 `fogDensity=0` |
| 独立 seed 派生与 `context.rng` 不一致导致复现争议 | 在 WIKI 记录 `environment` 随机源公式；固定 `?seed` 验收 |
| `environment` 在 `core/` 违反分层 | WIKI 3.1 加 L1.5 例外；若团队不接受，M1 改放 `app/environment.js`（仅改 import 路径与文档） |
| `weapon.setWetness` 合并规则改变手感 | M1 先用 `interior ? envWet*0.15 : envWet`，M6 可调；不改 `weapon.js` 内部 |

回滚方式：M1 所有改动可独立回退——删除两个新文件、还原 `runtime.js` 初始化/主循环、还原 `render/sky.js` 与 `renderer.js`、`config.js` 字段保留但不使用。`?time/weather` 参数在回滚后无效，不影响原版启动。
