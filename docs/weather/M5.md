## 3. 详细修改方案

### 3.1 `src/audio/audio.js` — `setWeather` / `setTimeOfDay`

**3.1.1 新增 `setWeather(w)`**

在 `createAudio` 返回对象（`Object.assign(Re, {...})`）内加：

```js
      setWeather(w) {
        // w: "clear" | "overcast" | "lightRain" | "heavyRain"
        const levels = {
          clear:     { rain: 0.0, wind: 0.2, sea: 0.6 },
          overcast:  { rain: 0.1, wind: 0.4, sea: 0.7 },
          lightRain: { rain: 0.6, wind: 0.6, sea: 0.8 },
          heavyRain: { rain: 1.0, wind: 0.9, sea: 0.9 },
        };
        const l = levels[w] || levels.clear;
        Oe.rain.setGain(l.rain * fe * (1 - 0.93 * P) * 0.95);
        Oe.rainIn.setGain(l.rain * fe * P * 0.95);
        Oe.wind.setGain(l.wind * fe * (0.3 + 0.7 * pt) * (1 - 0.65 * P) * 0.75);
        Oe.sea.setGain(l.sea * fe * (1 - 0.5 * P) * 1);
      },
```

**要点**：

- 现有 `lu(te)`（`update`）每帧已按 `fe/pt/P` 调 `Oe.rain/rainIn/wind/sea` 的 `gain`（第 1098–1104 行）。M5 的 `setWeather` 直接改 `gain` 会被下一帧 `update` 覆盖。
- **M5 正确做法**：引入 `weatherMul` 变量，`update` 中乘上 `weatherMul`：

```js
  let weatherMul = {
    rain: 0.6,   // 默认与原版一致
    wind: 0.5,
    sea: 0.7,
  };
  // ... 在 lu(te) 内：
  Oe.rain.setGain(fe * (1 - 0.93 * P) * 0.95 * weatherMul.rain);
  Oe.rainIn.setGain(fe * P * 0.95 * weatherMul.rain);
  Oe.wind.setGain(fe * (0.3 + 0.7 * pt) * (1 - 0.65 * P) * 0.75 * weatherMul.wind);
  Oe.sea.setGain(fe * (1 - 0.5 * P) * 1 * weatherMul.sea);
```

`setWeather(w)` 只改 `weatherMul`，`update` 下一帧生效。**这是 M5 唯一需要改 `update` 内 4 行的地方**。

**3.1.2 新增 `setTimeOfDay(t)` / `musicMood`**

`musicMood` 映射（`TIME_PRESETS` 已定义：`dawn=calm`、`noon=bright`、`dusk=warm`、`midnight=dark`）。

现有 `we(te)`（第 1040 行）返回 5 层 `[drone, perc, brass, motif, music_ost]` 的 `gain`：

```js
  function we(te) {
    return ee === "title"
      ? [0.85, 0, 0, 0, 0.9]
      : ee === "intro"
        ? [0.8, 0, 0, 0, 0.6]
        : ee === "dead"
          ? [0.75, 0, 0, 0, 0]
          : ee === "complete"
            ? [0.6, 0, 0, 0, 0.7]
            : [
                0.6 + 0.3 * te,
                Pv(0.05, 0.5, te) * 0.85,
                Pv(0.4, 0.8, te) * 0.95,
                Pv(0.62, 1, te) * 0.8,
                0,
              ];
  }
```

**M5 决策**：**不改 `we`**，因为 `we` 已按 `game.state` 与 `intensity` 返回 5 层，`musicMood` 的消费用**额外 `moodMul`**：

```js
  let moodMul = {
    calm:   { drone: 1.0, perc: 0.3, brass: 0.4, motif: 0.6 },
    bright: { drone: 0.7, perc: 1.0, brass: 1.0, motif: 0.9 },
    warm:   { drone: 0.9, perc: 0.6, brass: 0.8, motif: 0.8 },
    dark:   { drone: 1.2, perc: 0.4, brass: 0.3, motif: 0.5 },
  };
  // ... 在 Xe.layers 的 gain 更新处（第 1110 行附近）：
  let De = we(L),
    it = ye(1 / 0.5),
    mood = moodMul[musicMood] || moodMul.calm;
  for (let gt = 0; gt < tm.length; gt++) {
    let Ot = Xe.layers[tm[gt]];
    let target = De[gt] * (mood[tm[gt]] || 1);
    (Ot.c += (target - Ot.c) * it, (Ot.g.gain.value = Ot.c));
  }
```

`setTimeOfDay(t)`：

```js
      setTimeOfDay(t) {
        // t: "dawn" | "noon" | "dusk" | "midnight"
        musicMood = TIME_PRESETS[t]?.musicMood || "calm";
      },
```

**要点**：

- `musicMood` 变量在 `u_(i, e, t)` 内声明 `let musicMood = "calm"`。
- `moodMul` 是 5 层音乐层的额外倍率，与 `we` 的 `game.state` 基础值相乘。
- `tm = ["music_drone", "music_ost", "music_perc", "music_brass", "music_motif"]` 的顺序与 `we` 返回的 `[drone, perc, brass, motif, ost]` **不一致**（`we` 返回第 5 是 `music_ost`，`tm[1]` 是 `music_ost`）。M5 的 `moodMul` 按 `tm` 的键名索引，避免顺序问题。

**3.1.3 订阅 `environment:changed`**

在 `ln("game:state", ...)` 之后加：

```js
    ln("environment:changed", (te) => {
      if (te.weather) Re.setWeather(te.weather);
      if (te.timeOfDay) Re.setTimeOfDay(te.timeOfDay);

```

`ln` 是 `n.on` 的包装，`n` 是 `i.events`。**M5 不改 `ln`**。

**3.1.4 直升机 3D 跟踪完善**

M3 的 `helicopter.js` 已在 `update` 内每 0.1s（low 0.2s）调 `state.loop.setPos(state.pos)`。`audio.js` 的 `Be` 已支持 `setPos`。**M5 不改 `audio.js`**，只确认 M3 的 `helicopter.js` 已实现。若 M3 未实现，M5 在 `helicopter.update` 内补：

（M3 方案已含此逻辑，M5 只确认。）

**3.1.5 `library.js` 的 `helicopter` 音色**

### 3.2 `src/effects/effects.js` — `setRainIntensity(level)`

**3.2.1 新增 `setRainIntensity(level)`**

`effects.js` 现有雨幕实现（需确认）。M5 假设现有 `rain` 是 `ground.rain`（M1 确认 `ground.js` 有 `rain` 字段），`effects.js` 有独立粒子系统 `addEmitter`。

**M5 实现**：

```js
      setRainIntensity(level) {
        // level ∈ [0, 1]
        level = Math.max(0, Math.min(1, +level || 0));
        let maxParticles = (context.quality && context.quality.envRainParticles) || 3000;
        if (!rainEmitter) {
          rainEmitter = addEmitter({
            kind: "rain",
            pos: [0, 30, 0],
            count: Math.round(maxParticles * level),
            rate: 0.02,
          });
        } else {
          rainEmitter.setCount?.(Math.round(maxParticles * level)) ||
            rainEmitter.setRate?.(0.02 * level);
        }
        rainEmitter.visible?.(level > 0.01);
      },
```

**要点**：

- `addEmitter` 是 `effects.js` 现有接口（WIKI 4.5.1），返回 `{stop, setPos}`。**需确认是否有 `setCount/setRate/visible`**；若没有，M5 用“stop + 重建”或“改 `kind: rain` 的 emitter 的内部 state”。
- `maxParticles` 来自 `quality.envRainParticles`（M1 已加），`low` 2000 / `medium` 3000 / `high` 4000 / `ultra` 5000 / `test` 1600。
- `level` 来自 `target.rainLevel`（`clear=0`，`overcast=0`，`lightRain=0.45`，`heavyRain=1.0`）。

**3.2.2 `environment.pushFrame` 驱动**

`environment` 的 `pushFrame` 每帧调 `effects.setRainIntensity(c.rainLevel)`，与 `ground.setRain(c.rainLevel)` 并列：

```js
    if (context.ground && context.ground.setRain) {
      context.ground.setRain(c.rainLevel);
    }
    if (context.fx && context.fx.setRainIntensity) {
      try { context.fx.setRainIntensity(c.rainLevel); } catch (e) {}
    }
```

**3.2.3 `fallbacks.fx` 加 `setRainIntensity`**

```js

    // ... 现有
    setRainIntensity: noop,
  }),
```

### 3.3 `src/world/backdrop/backdrop.js` — `setLights(on, intensity)`

**3.3.1 新增 `setLights(on, intensity)`**

`backdrop.js` 现有 `lamps`（`Group` 或 `Array`）。M5 实现：

```js
      setLights(on, intensity) {
        // on: boolean, intensity: 0..1
        if (!lamps) return;
        lamps.traverse((m) => {
          if (m.isMesh && m.material && m.material.emissive) {
            m.material.emissiveIntensity = on ? 1 + intensity * 2 : 0;
          }
        });
      },
```

**要点**：

- `lamps` 若是 `Group`，用 `traverse`；若是 `Array`，用 `for`。
- `emissiveIntensity` 是 `MeshStandardMaterial` 的字段；若 `lamps` 用的是 `MeshBasicMaterial`（`emissive` 无 `emissiveIntensity`），改为 `m.material.opacity` 或 `m.material.color` 的 `multiplyScalar`。
- **需确认 `backdrop.js` 的 `lamps` 结构**，M5 开工前提供。

**3.3.2 `environment.applyStatic` 驱动**


### 3.4 `src/world/level/level.js` — `setLights(on, intensity)`

**3.4.1 新增 `setLights(on, intensity)`**

`level.js` 现有 `skylights` / `shedLights`。M5 实现：

```js
      setLights(on, intensity) {
        const apply = (group) => {
          if (!group) return;
          group.traverse((m) => {
            if (m.isLight) {
              m.intensity = on ? intensity * (m.userData.baseIntensity || 1) : 0;
            } else if (m.isMesh && m.material && m.material.emissive) {
              m.material.emissiveIntensity = on ? 1 + intensity * 2 : 0;
            }
          });
        };
        apply(skylights);
        apply(shedLights);
      },
```

**要点**：

- `skylights/shedLights` 可能是 `Array<PointLight>` 或 `Group`。`traverse` 兼容两者。
- `m.userData.baseIntensity` 在 `level.js` 创建灯时记录，避免 `setLights` 反复覆盖后丢失原始强度。**M5 需在 `level.js` 创建灯时加 `light.userData.baseIntensity = light.intensity`**。
- 若 `level.js` 现有 `skylights/shedLights` 是 `Mesh`（发光贴片），用 `emissiveIntensity`。

**3.4.2 `environment.applyStatic` 驱动**

```js
    if (context.level && context.level.setLights) {
      const on = state.target.lampOn > 0.05;
      context.level.setLights(on, state.target.lampOn);
    }
```

**3.4.3 `fallbacks.level` 加 `setLights`**

`fallbacks.js` 现有 `FALLBACKS` 无 `level`（`level` 是必需系统，初始化失败直接抛错）。**M5 不改 `fallbacks.js` 的 `level`**（不存在），只在 `environment.applyStatic` 用 `context.level && context.level.setLights` 防御。

### 3.5 `src/world/ground/ground.js` — `setReflections` 由画质 + 天气驱动

**3.5.1 `environment.applyStatic` / `pushFrame` 驱动**

M1 已确认 `ground.setReflections(enabled)` 存在。M5 在 `applyStatic` 内：

```js
    if (context.ground && context.ground.setReflections) {
      const planar = context.quality && context.quality.planar > 0;
      const wet = state.target.rainLevel > 0.3 || state.target.wetness > 0.4;
      context.ground.setReflections(planar && wet);
```

**要点**：

- `quality.planar`：`low=0`、`medium/high=0.5`、`ultra=1`、`test=0.5`。`planar=0` 时关闭。

- `setReflections` 是幂等的（`y.enabled = !!M`），每帧调无性能损失。

**3.5.2 不改 `ground.js`**

`setReflections` 已存在，M5 不改 `ground.js`。

### 3.7 `src/app/showcases.js` — `?show=environment`

**3.7.1 新增 `environmentShowcaseModule`**

在 `core/environment.js` 末尾加：

```js
var environmentShowcaseModule = {};
defineModuleExports(environmentShowcaseModule, {
  create: () => createEnvironment,
  showcase: () => showcaseEnvironment,
});

async function showcaseEnvironment(context) {
  // 环境模块已在 runtime 初始化，展示只负责相机与切换 UI
  let env = context.environment;
  let keys = ["dawn", "noon", "dusk", "midnight"];
  let weathers = ["clear", "overcast", "lightRain", "heavyRain"];
  let idx = { time: 0, weather: 0 };
  let update = (dt) => {
    // 每 4s 自动切换时间，每 3s 自动切换天气（展示用）
    idx.t = (idx.t || 0) + dt;
    if (idx.t > 4) {
      idx.t = 0;
      idx.time = (idx.time + 1) % keys.length;
      env.setTimeOfDay(keys[idx.time]);
    }
    idx.w = (idx.w || 0) + dt;
    if (idx.w > 3) {
      idx.w = 0;
      idx.weather = (idx.weather + 1) % weathers.length;
      env.setWeather(weathers[idx.weather]);
    }
  };
  return {
    cam: [-9, 1.7, 5.6],
    target: [14, 0.4, 5],
    update,
  };
}

export { createEnvironment, environmentShowcaseModule, showcaseEnvironment };
```
