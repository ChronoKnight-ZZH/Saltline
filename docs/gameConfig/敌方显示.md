## 实现方式：inverted hull（背面放大描边）

没动你那套自写 HDR 后处理管线（往里塞 OutlinePass 风险大），而是给每个敌人挂一层红色外壳：

- **新文件 `src/render/enemy-outline.js`**：遍历 `enemies.list`，对每个存活敌人克隆其 group 下所有 Mesh/SkinnedMesh，换成红色 `BackSide` 材质、整体放大 1.07 倍——从背面看就是一圈描边。SkinnedMesh 共享原 skeleton，轮廓跟着骨骼动画动。
- **接入 `runtime.js`**：import 后在 environment 装配后 `createEnemyOutline(context)`，主循环在 `enemies.update` 之后加 `updateSystem("outline", p)`。失败 try/catch 不崩游戏。

## 你提的两个要求怎么落地

| 要求 | 实现 |
|---|---|
| **视角内可见** | 外壳挂在 `enemy.group` 下，Three.js 默认 `frustumCulled`——group 离开相机视锥时整棵子树（含轮廓）根本不渲染，天然只在视野内出现。 |
| **视距裁剪** | 每帧算敌人到 `context.camera.position` 距离：>60m 隐藏；45–60m 之间透明度线性渐隐到 0。不是硬切，是平滑淡出。 |

可调参数在 `enemy-outline.js` 顶部：
- `OUTLINE_COLOR = 0xff3030`（红边颜色）
- `MAX_DIST = 60` / `FADE_START = 45`（裁剪距离）
- `PAD = 1.07`（描边粗细，越大边越粗）
