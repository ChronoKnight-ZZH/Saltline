# M6 修改方案：武器系统与地图弹药补给

> 依据：`docs/武器与弹药补给系统设计.docx`（v1.0，2026-11-15，`feature/weapon-ammo`）+ 当前 `src/` 实测。
>
> 结论先行：设计稿的数值全部能落在现有接口上，但有 **4 处代码硬约束必须先改**：
> 1. 武器数值是模块级常量（`weapon.js:29-37`），不是可替换的配置；
> 2. `combat.playerShot` 是单射线、`stats.shots` 每发 +1（`combat.js:18-29`），霰弹的多弹丸无法直接表达；
> 3. 交互提示只有"按住 E"一种形态（`hud.js:347`），补给要的是"轻按 E"；
> 4. 关卡静态网格会整体合批（`level.js:126`），补给箱必须走 dynamic，否则变灰/光晕改不动。

### 1.3 M6 完成后可观察到的变化

- 简报页出现 4 张武器卡，选 ASH-12 进场后 HUD 名称为 `ASH-12 Guttersnipe`，弹匣 40、备弹 160。
- 游戏中按 `1/2/3/4`（或滚轮、手柄肩键）切枪，视图模型先降后抬（约 0.55s），换枪不清空已装弹匣。
- 走到任意补给箱 2m 内出现 `Press E — resupply`，按 E 后：当前武器备弹补满、同口径/邻接武器 +30%，箱子光晕消失并变灰，本局不可再用。
- 5 个补给箱位置与设计稿一致，但每个都经过 `isWalkable` 吸附（不会嵌进集装箱或落水）。
- 耀斑峰值段（`solarflare.effect > 0`）补给提示变为 `EMP — lock online`，按 E 无效，耀斑结束后 1s 恢复。
- `?show=weapon&weapon=ash12` 可直接检视任一把武器的视图模型与手位。

## 2. 前置核实（研究结论）

### 2.1 武器侧

| 单武器数值是模块级常量：`Gv=30`（弹匣）、`B_=150`（备弹）、`O_=720`（RPM）、`H_=26`（伤害）、`V_=300`（射程） | `weapon.js:29-37` | 必须改成读 `def`，否则 4 把武器无法共存 |

### 3.2 `src/weapons/weapon.js` 参数化

改造原则：**只把常量换成 `def` 字段，不动动画与弹簧结构**，保证 `?show=weapon` 的观感不回退。

```js
async function createWeapon(context, def) {
  def = def || WEAPONS[DEFAULT_LOADOUT];
  ...
  let ve = {
    name: def.name,
    def,
    slot: def.slot,
    ammoType: def.ammoType,
    ammo: def.magSize,
    magSize: def.magSize,
    reserve: Math.min(def.reserveStart, def.reserveMax),
    ...
    addAmmo(n, cap = def.reserveMax) {
      ve.reserve = Math.min(cap, ve.reserve + Math.max(0, +n || 0));
      return ve.reserve;
    },
    ammoRoom: () => def.reserveMax - ve.reserve,
  };
```

| `:423` | `name: mi.name` | `name: def.name` |
| `:424-426` | `ammo/magSize/reserve` 用 `Gv/B_` | 用 `def.magSize/reserveStart` |
| `:430-431` | `damage: H_`、`rpm: O_` | `def.damage`、`def.rpm` |

扩散与天气的合成（保持现有"环境倍率只作用于弹道、不写回 `ve.spread`"约定，`weapon.js:550-557`）：

```js
function shotSpread(def, adsE, wet) {
  let base = lerp(def.spreadHip, def.spreadAds, adsE);
  let env = (context.environment && context.environment.perception.spreadScale) || 1;
  // 只对雨天与暴雨生效：晴/阴 spreadScale 本来就是 1.0，无需再判
  let rain = env > 1 ? (def.wetMul || 1) : 1;
  return base * env * rain;
}
```

开镜 FOV（`player.js:509` 用的常量与 `player.tuning` 是同一对象）：

```js
// 切枪时：context.player.tuning.fovAds = def.fovAds;
// 更干净的写法（推荐）：player.setAdsFov(def.fovAds)，镜头读 C.adsFov ?? PLAYER_MOVEMENT.fovAds
```

### 3.3 新增 `src/weapons/system.js`

```js
// Weapon switching, per-weapon ammo and the context.weapon contract.
async function createWeaponSystem(context) {
  let byId = new Map(), order = WEAPON_ORDER.slice(), active = null, switching = 0;
  let pending = null;               // { id, t, phase: "down" | "up" }

  async function build(def) {
    let w = await createWeapon(context, def);
    w.setVisible(false);
    w.root.name = "viewmodel-" + def.id;
    byId.set(def.id, w);
    return w;
  }

  async function init() {
    for (let id of order) await build(WEAPONS[id]);
    select(DEFAULT_LOADOUT, { immediate: true });
  }

  function cycle(dir) {
    let i = order.indexOf(active.id);
    select(order[(i + dir + order.length) % order.length]);
  }

  return {
    get list() { return order.map((id) => byId.get(id)); },
    get activeId() { return active && active.id; },
    select(id, { immediate = false } = {}) {
      let next = byId.get(id);
      if (!next || next === active) return false;
      if (immediate) return swap(next);
      // 0.22s 降枪 → 交换 → 0.33s 抬枪，期间 noFire
      if (switching <= 0) (pending = { id, t: 0, phase: "down" }), (switching = 0.55);
      return true;
    },
    cycle,
    slots() {
      return order.map((id) => {
        let w = byId.get(id);
        return { id, slot: WEAPONS[id].slot, name: WEAPONS[id].name,
                 short: WEAPONS[id].short, ammoType: WEAPONS[id].ammoType,
                 ammo: w ? w.ammo : 0, reserve: w ? w.reserve : 0,
                 active: !!active && active.id === id };
      });
    },
    ammoFor(type) { /* 聚合某口径总备弹，供 HUD/补给点判定 */ },
    fill(type, amount) { /* 对同口径每把枪 addAmmo(amount) */ },
    update(dt) { /* pending 状态机 + slot 输入 + context.weapon 指向 + player.tuning.fovAds */ },
    reset(loadoutId) { /* 全部 reset，回到 loadoutId，清 pending */ },
    debug: { byId },
  };
}

export { createWeaponSystem };
```

关键约定：

- **`context.weapon` 仍然存在**，只是从"唯一武器"变成"当前活跃武器实例"。`hud/player/flow/runtime` 一行都不用改（已核实这四处只做鸭子类型读取）。
- 切枪窗口用 `active.debug.noFire = true` 屏蔽开火（`weapon.js:626` 已读该位），不需要新状态机。
- 每把武器保留自己的 `ammo/reserve`，切走再切回不清弹匣 —— 这是设计稿 §5.1 "不同武器弹药分开计数"在前端的落点。
- `reset()` 由 `flow.H()` 调用一次，替代现在的 `a(context.weapon, "reset")`。

#### 3.4.3 新增 `src/game/supply.js`

```js
// Ammo resupply points: proximity, one-shot use, EMP lock.
var KINDS = {
  mixed: { types: ["pistol", "smg", "dmr", "shell"], mul: 0.5 },  // S1：四类各 50%
  light: { types: ["pistol", "smg"], mul: 1 },
  heavy: { types: ["dmr", "shell"], mul: 1 },
  shell: { types: ["shell"], mul: 1 },
  dmr: { types: ["dmr"], mul: 1 },
};

function createSupply(context) {
  let spots = (context.level.supplySpots || []).map(cloneMeta);
  const RADIUS = 2.0, OTHER_MUL = 0.3;

  function nearest(eye, forward) { /* 同 flow.$()：2m + 朝向点积 > 0.45，返回最近 spot */ }

  function usable(spot) {
    if (spot.used) return "used";
    // 耀斑峰值段（effect=1）电子锁失效；起升/回落段仍可用
    if (context.solarflare && context.solarflare.effect > 0) return "emp";
    return null;
  }

  function use(spot) {
    let why = usable(spot);
    if (why) return why;
    let sys = context.weaponSystem,
      kind = KINDS[spot.kind] || KINDS.mixed,
      filled = [];
    for (let w of sys.list) {
      let def = w.def;
      if (!kind.types.includes(def.ammoType)) continue;
      // 当前武器按 kind.mul 补（专用点 = 补满），其它同口径 +30%；addAmmo 内部按 reserveMax 钳制
      let add = w === sys.active ? Math.ceil(def.reserveMax * kind.mul)
                                 : Math.ceil(def.reserveMax * OTHER_MUL);
      let before = w.reserve, after = w.addAmmo(add);
      after > before && filled.push({ id: def.id, got: after - before });
    }
    if (!filled.length) return "full";        // 已经满弹：不消耗补给点，只提示一次
    spot.used = !0;
    spot.object.userData.setState("used");
    context.events.emit("supply:used", { id: spot.id, kind: spot.kind, filled });
    return null;
  }

  return {
    spots, nearest, usable, use,
    reset() { for (let s of spots) (s.used = !1), s.object.userData.setState("live"); },
    get remaining() { return spots.filter((s) => !s.used).length; },
    debug: { spots },
  };
}
```

|---|---|---|
| `mixed`（S1） | `+ceil(reserveMax * 0.5)` | `+ceil(reserveMax * 0.3)` |
| 专用点（S2–S5） | `+ceil(reserveMax * 1.0)`（补满） | `+ceil(reserveMax * 0.3)` |

- 补的是**备弹**，不直接塞弹匣；弹匣仍由玩家按 R 换（保持换弹动画与音频节奏）。
- `full` 返回值让 flow 提示 `Ammo full`，且**不消耗**该点 —— 避免玩家跑一趟发现箱子空了。

### 3.9 `src/combat/combat.js` — 多弹丸与距离衰减

```js
playerShot(origin, dir, {
  damage: dmg = 28, range = 300, impulse = 1,
  pellets = 1, pelletCone = 0, falloff = null, style = "pistol",
} = {}) {
  e.shots++;                                   // 一次扣扳机只算 1 发
  let best = null, anyHit = false;
  for (let i = 0; i < pellets; i++) {
    let d = i === 0 ? dir : perturb(dir, pelletCone);   // 第一颗走准心
    let out = castOne(origin, d);                        // 原 24-83 行逻辑抽成内部函数
    if (out && out.enemy) {
      anyHit = true;
      let mul = falloff ? falloffMul(falloff, out.dist) : 1;
      out.enemy.damage(dmg * (out.part === "weak" ? 2.2 : 1) * mul, ...);
      if (!best || out.dist < best.dist) best = out;
    }
    context.events.emit("impact", out);                  // 每弹丸都出弹着特效
  }
  if (anyHit) e.hits++;                                 // 命中率按"扣扳机次数"算
  best && context.events.emit("player:hitEnemy", ...);   // 只有最近一发打命中标记
  return best;
}
```

要点：

- **命中率分母**：`stats.shots` 每扣扳机 +1，不是每弹丸 +1，否则结算页命中率会崩（霰弹最多 800%）。
- **命中标记**：8 颗弹丸只出 1 次 `player:hitEnemy`，否则 HUD 命中音效叠 8 层。
- 弹着特效应逐颗出（`impact`），霰弹的墙面弹着才好看，但视觉上不触发 8 次 hitmarker。
- `perturb(dir, cone)` 用与武器相同的随机源，保证 `spread` 与弹丸扩散互不重复。

## 4. 性能与降级

| 风险 | 量级 | 处理 |
|---|---|---|
| 4 份 viewmodel 几何 | 每把 `info.tris` 同量级，合计约 4×（§验收里实测） | 启动阶段构建；若合计 > 6 万三角形，改为"简报确认后预构建" |

## 7. 风险与回滚

| 风险 | 触发条件 | 缓解 | 回滚 |
|---|---|---|---|
| 手位/枪口对不上，枪"浮手" | 附件层改变了握把与前握距离 | 每把枪 `hands.left/right` 独立；`?show=weapon` 里用 `snap()` 逐帧调 | 该武器暂时用原手位 + 关闭 kit 中前后向附件 |
| 4 份 viewmodel 拖慢启动 | 三角形/材质合计过高 | 简报确认后按需构建；`?q=low` 只构建当前枪 | `WEAPON_ORDER` 缩到 2 把 |
| 切枪打断换弹导致状态错乱 | 换弹中按 1–4 | `switchT` 期间忽略输入；`select()` 前检查 `state === "reloading"` 则拒绝 | 只允许在 `idle` 切枪 |
| 补给箱嵌入静态件 | 坐标吸附失败（2m 内无可走格） | 吸附后 `console.warn`；A5 清单逐点验 | 该点回退到最近 `coverPoint` |

| 命中率统计崩 | 霰弹按弹丸计入 `shots` | §3.9 明确 1 次扣扳机 = 1 | 结算页显示 `pellets` 口径 |
| 环境倍率与武器倍率重复相乘 | 雨天实际 1.35 × 1.5 = 2.0，过飘 | `wetMul` 只在 `spreadScale > 1` 时生效，且上限 `env * rain ≤ 1.8` | `wetMul` 全置 1，只用全局 |
