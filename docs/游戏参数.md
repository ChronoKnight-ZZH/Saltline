# 当前时间/天气对玩家/敌方影响的关键参数表

> 依据：M1 已落地的 `TIME_PRESETS` / `WEATHER_PRESETS` / `combine()`（`core/environment-presets.js`），M2 已落地的 `effectiveSightRadius` / `alert` 遮蔽 / `spreadScale`（`enemies.js` / `weapon.js` / `hud.js`），以及 `ENEMY_TUNING` / `WALKER_TUNING` / `DRONE_TUNING` / `WEAPON` 的基础值。以下数值是**代码里实际生效的**，不是方案里的建议值。

## 3. 组合后对玩家/敌方的**实际影响**

### 3.1 敌人视觉半径（M2 `enemies.js#think`）

`effectiveSightRadius = min(perception.visibility, ENEMY_TUNING.sightRange × perception.visualAlert)`

- `ENEMY_TUNING.sightRange = 45`（`enemies.js` 第 22 行，M2 决策 A **未调**）
- `perception.visualAlert = 1.0`（M1 `environment.perception` getter）
- `perception.visibility = time.visibility × weather.visibilityMul`

| 时间 \ 天气 | clear | overcast | lightRain | heavyRain |
|---|---|---|---|---|
| dawn（180） | `min(180, 45) = 45` | `min(140.4, 45) = 45` | `min(90, 45) = 45` | `min(50.4, 45) = 45` |
| noon（220） | `min(220, 45) = 45` | `min(171.6, 45) = 45` | `min(110, 45) = 45` | `min(61.6, 45) = 45` |
| dusk（160） | `min(160, 45) = 45` | `min(124.8, 45) = 45` | `min(80, 45) = 45` | `min(44.8, 44.8) = 44.8` |
| midnight（90） | `min(90, 45) = 45` | `min(70.2, 45) = 45` | `min(45, 45) = 45` | `min(25.2, 25.2) = 25.2` |

**结论：只有 `dusk/heavyRain`（44.8m）和 `midnight/heavyRain`（25.2m）两格视觉半径缩小，其余 14 格全部是 45m。** 这是实测“效果不明显”的**首要原因**。

### 3.2 敌人听觉半径（M2 `enemies.js#alert`）

`effD = radius × (1 - min(0.9, audioMask))`

- `weapon:fire` 的 `radius = ENEMY_TUNING.hearRadius = 45`
- `explosion` 的 `radius = 30`

| 时间 \ 天气 | clear | overcast | lightRain | heavyRain |
|---|---|---|---|---|
| 任意时间·开枪 | 45m | `45×0.9=40.5m` | `45×0.5=22.5m` | `45×0.28=12.6m` |
| 任意时间·爆炸 | 30m | `30×0.9=27m` | `30×0.5=15m` | `30×0.28=8.4m` |

**结论：听觉遮蔽是 M2 里唯一“效果明显”的参数**——`heavyRain` 下开枪唤醒半径从 45m 缩到 12.6m，玩家感知强。但**只在开枪/爆炸时触发**，平时跑动（脚步）不走 `alert`，所以“平时看不出雨天区别”。

### 3.3 射击扩散（M2 `weapon.js#Be` + `hud.js#se`）

`实际 spread = ve.spread × spreadScale`，`ve.spread` 基础值约 `0.0125`（ADS 更低、移动更高）。

| 时间 \ 天气 | clear | overcast | lightRain | heavyRain |
|---|---|---|---|---|
| 任意时间·基础扩散 | `×1.00` | `×1.00` | `×1.05` | `×1.15` |
| 准星间距变化 | — | 0% | +5% | +15% |

**结论：+5% / +15% 的准星与弹道变化，视觉上很难感知**，尤其 ADS 下基础扩散只有 `0.0012`，`×1.15` 后是 `0.00138`，肉眼几乎看不出。

### 3.4 能见度（`perception.visibility`，M2 只用于敌人视觉上限）

| 时间 \ 天气 | clear | overcast | lightRain | heavyRain |
|---|---|---|---|---|
| dawn | 180 | 140.4 | 90 | 50.4 |
| noon | 220 | 171.6 | 110 | 61.6 |
| dusk | 160 | 124.8 | 80 | 44.8 |
| midnight | 90 | 70.2 | 45 | 25.2 |

**结论：`perception.visibility` 本身变化很大（25.2–220），但 M2 只用它做 `min(visibility, 45)`，被 `sightRange=45` 钳死，玩家看不到这个数值的效果。**

### 3.5 视觉/表现层（M1 已落地，但 M3 阶段未接完）

| 表现 | 状态 | 玩家可感知 |
|---|---|---|
| 太阳颜色/强度 | M1 `renderer.setSun` 已写 `h.color/h.intensity` | 场景亮度变化**中等**（`midnight` 明显暗） |
| 天空色 `uZen/uHor` | M1 `applySkyPreset` 已写 | 天空颜色变化**明显** |
| 雾密度/颜色 | M1 `renderer.setFog` 已写 | **`heavyRain` 下雾明显，`clear` 几乎无雾**（`fogDensity ≈ 9.1e-5`） |
| 曝光 | M1 `renderer.setExposure` 已写 | `midnight=0.7` 比 `noon=1.05` 暗**中等** |
| 地面雨量/湿度 | M1 `ground.setRain` / `mats.uniforms.wet` 已写 | 地面湿润/积水**中等** |
| 武器湿度 | runtime `weapon.setWetness` 已写 | 视图模型湿润**弱**（需细看） |
| 环境光 `ambient` | **M1 未消费** | **无** |
| 太阳方向 `sunDir` | **M1 不移动 `h.position`** | **无**（阴影方向不变） |
| 灯光 `lampOn` | **M5 才消费** | **无**（M3 阶段灯不亮） |
| 音乐 `musicMood` | **M5 才消费** | **无** |
| 雨幕粒子 | **M5 才消费** | **无**（只有 `ground.rain` 的水面涟漪） |
| 平面反射 | **M5 才消费** | **无**（`ground.planar` 默认按画质开，但不随天气变） |

## 4. 为什么“效果不明显”——按重要性排序

| # | 原因 | 参数 | 修复里程碑 |
|---|---|---|---|
| 1 | **`sightRange=45` 钳死敌人视觉半径**，14/16 格组合都是 45m | `ENEMY_TUNING.sightRange=45` vs `time.visibility × weather.visibilityMul` | M6 调 `sightRange` 到 120（M2 决策 B）或引入“能见度系数” |
| 2 | **`ambient` 未消费** | `TIME_PRESETS.ambient`（0.35–1.15） | M5/M6 在 `renderer` 加 `ambient` 或 `hemisphereLight` |
| 3 | **`sunDir` 不移动** | `TIME_PRESETS.sunDir` | M6 在 `renderer.setSun` 调 `Gy` 重拟合阴影 |
| 4 | **`lampOn` 未消费** | `TIME_PRESETS.lampOn`（0–1） | M5 `backdrop/level.setLights` |
| 5 | **`musicMood` 未消费** | `TIME_PRESETS.musicMood` | M5 `audio.setTimeOfDay` |
| 6 | **雨幕粒子未消费** | `WEATHER_PRESETS.rainLevel` | M5 `effects.setRainIntensity` |
| 7 | **平面反射不随天气变** | `ground.setReflections` | M5 |
| 8 | **`spreadScale` ±5/15% 太弱** | `WEATHER_PRESETS.spreadScale` | M6 调大到 1.3/1.6，或改为“开镜抖动/后坐力” |
| 9 | **`visibility` 只用于 `min`，玩家看不到** | `perception.visibility` | M6 引入“雾/渲染距离”直接消费，或 HUD 显示能见度 |
| 10 | **听觉遮蔽只在开枪/爆炸触发** | `audioMask` | M6 把脚步/跑动也接入 `alert`，让雨天“走路更安全”可感知 |

## 6. 建议的 M5/M6 优先级

**M5 先做（表现层，不改玩法数值）**：

1. `lampOn` → `backdrop/level.setLights`（夜晚灯亮，玩家一眼看出时间）
2. `rainLevel` → `effects.setRainIntensity`（雨天雨幕可见）
3. `musicMood` → `audio.setTimeOfDay`（氛围）
4. `audioMask` → `audio.setWeather`（雨声/风声，强化听觉遮蔽的“感知”）
5. `ground.setReflections` 随天气（雨天地面反光）

**M6 再调（玩法数值）**：

1. **`sightRange` 45 → 120**（M2 决策 B），让 `midnight/heavyRain` 的 25.2m、`dusk/heavyRain` 的 44.8m、`midnight/lightRain` 的 45m 真正生效
2. **`spreadScale` 1.05/1.15 → 1.25/1.5**，或改为“雨天开镜晃动”
3. **脚步/跑动接入 `alert`**，让 `audioMask` 在非开枪时也可感知
4. **`ambient` 接入 `hemisphereLight`**，`midnight` 环境光 0.35 明显更暗
5. **`sunDir` 接入 `Gy` 重拟合**，阴影方向随时间变

**M6 调参前建议先做 M5**，否则“夜晚灯不亮、雨天没雨幕、音乐不变”，玩家感知不到时间/天气切换，调 `sightRange` 也白搭。
