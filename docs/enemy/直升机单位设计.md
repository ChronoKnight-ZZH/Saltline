# 巡逻直升机单位设计（行为 / 照明 / 导弹齐射 / 爆炸交互）

> 本文档把 `world/helicopter.js` 从"环境探照灯"升级为**可交战的夜间敌对单位**。
> 触发条件沿用环境系统：仅 `midnight × clear/overcast` 出现（夜雨停飞）。
> 复用现有契约：敌人状态机范式、`enemy:telegraph` 预警、`combat.explode` 范围伤害、`fx.explosion` 视觉爆炸、交战 token。
> 本文数值为 v1 设计初值，标注「待校准」。

---

## 1. 定位

一架在港口上空盘旋的敌方武装直升机。它不是站桩炮台，而是一个**移动照明 + 导弹压制**单位：

- **平时**：绕场盘旋，探照灯扫过地面（照明功能，沿用 M3 光柱）。
- **照到玩家**：光柱锁定、拉警报，短暂预警后**齐射导弹**压制。
- **玩家反制**：在锁定窗口躲进掩体打断；导弹落地前跑出爆炸圈。

与地面敌人（Gull/Hound）的区别：它在 28m 高空、靠**信息（照明暴露）+ 范围伤害（导弹）**施压，不会落地追你；玩家可以开枪把它打下来（见 §6）。

## 2. 状态机

```
        ┌──────────────────────────────────────┐
        ▼                                      │
     patrol ──光柱照到玩家(LOS)──► alert ──持续照到 lockOnTime──► lock
   (盘旋扫光)                     (光柱跟踪玩家)                  │
        ▲                            │                          ▼
        │                            │ 照丢/躲进掩体          telegraph
        │                            └──────复位──────────┐   (0.9s 预警)
        │                                                 ▼
        │                                             engage
        │                                          (齐射 2 枚导弹)
        │                                                 │
        │                                                 ▼
        └────────── cooldown(6s, 盘旋扫光) ◄──── 导弹落地爆炸
```

| 状态 | 行为 |
|---|---|
| **patrol 巡逻** | 绕轨道匀速盘旋，光柱随机慢扫（左右 ±30° 摆头），低频旋翼声。 |
| **alert 警觉** | 光柱**锁定跟踪**玩家当前位置（不再自由扫），轨道减速，警报音渐强，HUD 提示"探照灯锁定中"。 |
| **lock 锁定** | 光柱稳定照住玩家满 `lockOnTime`，触发红框地面标记 + 电子蜂鸣（telegraph）。 |
| **engage 齐射** | 向锁定点发射 `missileCount` 枚导弹；机炮/直射不开火。 |
| **cooldown 冷却** | 齐射后 6s，光柱松开玩家恢复扫光，等下一次接近窗口。 |

**复位规则**（复用 Hound `investigate` 的 2s 最短驻留思想）：
- alert/lock 期间玩家**离开光柱 LOS**（躲进建筑/集装箱阴影）超过 `lockOnTime` 的一半 → 退回 patrol，光柱继续扫。
- 已 lock 后玩家再躲也**不取消已发射的导弹**（导弹照打原锁定点），但打断后续齐射。
- `game:state` 非 playing 冻结全部行为，不清状态（沿用 M3 冻结规则）。

## 3. 盘旋与飞行

| 参数 | 值 | 说明 |
|---|---|---|
| `orbitRadius` | 45 m | 绕地图中心 / 当前扇区盘旋半径 |
| `orbitHeight` | 28 m | 巡航高度（高于屋顶） |
| `patrolSpeed` | 6 m/s | 巡逻绕圈速度（一圈约 47s） |
| `alertSpeed` | 3.5 m/s | 警觉/锁定时绕得更慢更紧，给玩家追踪时间 |
| `bobAmp` | 1.5 m | 高度小幅起伏，避免机械直线 |
| `bobFreq` | 0.3 Hz | 起伏频率 |

飞行路径用 `context.rng.fork()` 派生可复现轨道（沿用 M3 随机源约定），不用真实物理。

## 4. 照明（复用 M3 光柱）

沿用现有 `beam` 锥体 + `isInBeam(pos)`（锥体判定 + `physics.lineOfSight`）：

| 参数 | 值 |
|---|---|
| `beamHalfAngle` | 14° |
| `beamRange` | 40 m |
| `exposeInterval` | 0.25 s（`low` 0.5s） |

行为差异：
- **patrol**：光柱在机头朝向左右 ±30° 缓慢摆扫。
- **alert/lock**：光柱方向**插值指向玩家最后已知位置**，`_onHelicopterSpot` 照常写 `lastKnown` + 触发地面敌人 investigate（沿用 M3 暴露扫描）——即直升机照到你，会同时惊动附近地面敌人，这是它"照明"的战术价值。

## 5. 导弹齐射（核心战斗行为）

### 5.1 流程

```
lock 完成
  └─► telegraph 0.9s
        ├─ 地面红色冲击标记出现在【锁定瞬间的玩家位置】（不追踪移动）
        ├─ 机头导弹舱闪光 + 发射蜂鸣
        └─ HUD 警告音
  └─► 依次发射 missileCount 枚，间隔 missileInterval
        └─ 每枚导弹从机腹出发，飞向【发射时锁定点】
  └─► 导弹落地 = 爆炸（§6）
```

**关键设计**：导弹打的是**锁定瞬间的地面点，不是追踪制导**。玩家看见红标 + 烟迹后，跑离该点即可躲开——这是主要反制手段。

### 5.2 导弹参数

| 参数 | 值 | 说明 |
|---|---|---|
| `missileCount` | 2 | 一轮齐射数量 |
| `missileInterval` | 0.35 s | 两弹间隔（第二枚略偏 ±1.5m，覆盖走位） |
| `missileSpeed` | 26 m/s | 对地飞行速度 |
| `lockOnTime` | 1.2 s | 光柱持续照满才锁定 |
| `telegraphTime` | 0.9 s | 锁定→发射预警（玩家看见红标） |
| `reEngageCooldown` | 6.0 s | 一轮齐射后再次锁敌冷却 |
| `spreadOffset` | ±1.5 m | 第二枚弹着点散布 |

**躲避窗口实算**：典型斜距 35–50m / 26m/s ≈ **1.4–1.9s** 从发射到落地。加上 telegraph 0.9s，玩家共约 **2.3–2.8s** 反应；冲刺速度约 7m/s，可移出 15m 以上——足够脱离 5m 爆心，但**不能站着不动**。

## 6. 爆炸交互（本次重点设计）

导弹落地调用**现有**两段式，不新造伤害模型：

### 6.1 视觉与音效
```js
context.fx.explosion(impactPos, 1.6);          // 复用：火球/烟/光 + 派发 explosion 事件
context.audio.play("explosion", { pos: impactPos });
context.player.addShake(0.6);                   // 近距离震屏
```
- `explosion` 事件对象复用，订阅方立即拷贝 `pos/size`（沿用 WIKI §4.5 注意事项）。

### 6.2 范围伤害
```js
context.combat.explode(impactPos, 5.0, 30, "helicopter");
```
复用 `combat.explode(pos, radius, damage, from)` 的既有规则（WIKI §4.4.3）：

| 项 | 值 / 规则 |
|---|---|
| `radius` | **5.0 m** 爆风半径 |
| `damage` | **30**（爆心基础值） |
| 对敌人 | 距离线性衰减（复用原规则） |
| 对玩家 | **50% 衰减**（复用原规则）→ 爆心实际约 **15–20**，边缘 0 |
| 视线 | 要求 LOS（导弹从天上下来，地面目标通常满足） |

### 6.3 玩家受击反馈
- 直接命中爆心（15–20 伤害）+ `player.damage(amount, impactPos)` 的震屏/红屏。
- 玩家满血假设沿用现有 `maxHealth`（WIKI 未列具体值，按现有扣血节奏：两枚都中≈半血，给一次吃满被秒的风险感但不秒杀满血）。
- 爆点边缘：擦到 3–6 伤害 + 强震屏，提示"躲开了但差点"。

### 6.4 与雷声/雨的协同
- 直升机仅夜晴出现，无雨声遮蔽，旋翼声 30m 内本身就是脚步掩蔽（沿用 M3 `maskRadius: 30`）。
- 爆炸声会 `enemies.alert(impactPos, 30)` 惊动地面敌人——炸点附近的地面怪被火光噪声吸引，形成"直升机炸你→也把怪引来"的复合压力。

## 7. 玩家反制手段

| 威胁 | 反制 |
|---|---|
| 光柱照到（alert） | 立刻躲进建筑/集装箱阴影，打断锁定 |
| 红标出现（telegraph） | 跑出红标圈，或找硬质掩体（导弹打地面，掩体后不受伤） |
| 导弹烟迹 | 横向移动别直跑，第二枚有 ±1.5m 散布 |
| 直升机本体 | 可射击击落（§8） |

## 8. 生存力（可击落，v1 可选开启）

| 参数 | 值 | 说明 |
|---|---|---|
| `hp` | 120 | 玩家 PAC-9 伤害 26/发（弱点 ×2.2） |
| 击落判定 | 命中机体/旋翼 | 用现有 `combat.playerShot` 射线命中，part 标记 |
| 击落演出 | `fx.explosion(pos, 2.5)` 大爆炸 → 坠落 → 二次爆炸 |
| 掉落 | 无（环境单位，不送装备） |

> 待校准：120 HP ≈ 5 发弱点 / 9 发身体。若击落太容易，把 hp 提到 180 或加机动规避；若玩家根本打不到，降低 hp 或在 alert 时机头短暂悬停暴露。

## 9. 参数总表（标注复用来源）

```js
HELI_UNIT_TUNING = {
  // —— 飞行 ——
  orbitRadius: 45, orbitHeight: 28,
  patrolSpeed: 6, alertSpeed: 3.5,
  bobAmp: 1.5, bobFreq: 0.3,

  // —— 照明（沿用 M3）——
  beamHalfAngle: 14, beamRange: 40,
  exposeInterval: 0.25,

  // —— 锁定 ——
  lockOnTime: 1.2,

  // —— 导弹 ——
  missileCount: 2, missileInterval: 0.35,
  missileSpeed: 26, telegraphTime: 0.9,
  reEngageCooldown: 6.0, spreadOffset: 1.5,

  // —— 爆炸（复用 combat.explode / fx.explosion）——
  blastRadius: 5.0, blastDamage: 30,

  // —— 生存 ——
  hp: 120,
}
```

**复用无人机（Hound）的部分**：
- 状态机范式 `patrol→investigate(alert)→search→engage→dead`。
- `enemy:telegraph` 预警事件（发射前 0.9s 派发，音频/HUD 订阅）。
- 交战 token：直升机占 1 个 token（默认同屏 2、>5 敌 3），与地面敌人共享配额。
- `combat.enemyShot` / `combat.explode` / `fx.explosion` 同一战斗接口。
- 死亡爆炸复用 `fx.explosion(pos, size)` + `enemy:killed` 事件链。

**直升机独有**：高空盘旋、锥体照明、非制导导弹齐射、可击落。
