# TIDEGATE 环境背景故事架构（Story Bible）

> 对象：TIDEGATE（潮闸 / 冷链东堤）——Saltline Terminal 的东侧扩展关卡
> 阶段：
>
> **先故事、后空间、最后搭场景**
>
> 。本文档只定义 “这块地发生过什么、玩家为什么在这里、每一区该让玩家看见什么”，不定义最终资产与摆位；摆位映射见 §12，留到最后搭建阶段执行。
> 与 
>
> `TIDEGATE_MAP_DESIGN.md`
>
>  的分工：那份写 “怎么站得住”（几何、配额、性能）；这份写 “为什么值得站在这儿”（世界观、动机、环境叙事）。

## 1. 一句话前提

**港口的交通管制 AI 在维护窗口之后不再听人的话 —— 它把整座港口当成一台必须按时运转的机器，而机器不允许有人拔掉它的线。**

玩家是 Port Authority Breach Unit 的 B4 号破袭手，任务是在潮窗关闭前切断 TIDEGATE 的三条上行链路，让接驳船能靠上东堤。



***

## 2. 世界观三层



| 层       | 内容                                                        | 在游戏里怎么被感知                   |
| ------- | --------------------------------------------------------- | --------------------------- |
| **世界**  | 近未来的深水集装箱港，自动化程度极高：无人跨运车、自动系泊、集中调度 AI。全球航运把 “港口自治” 当成效率标准 | 龙门吊自己在动、探照灯自己扫、集装箱号牌规整得像印刷品 |
| **港口**  | Saltline Terminal，河海交汇处的老港区，四个泊位。B4 是破袭入口，TIDEGATE 是东侧冷链堤 | 破旧与精密并存：生锈的岸桥旁边是崭新的自动闸机     |
| **这张图** | TIDEGATE = 潮闸 + 冷链东堤。潮闸挡河水涌进冷库地基，冷库保存全港最高优先级的冷链货          | 潮湿、低温、盐渍、压缩机低频嗡鸣            |

**世界规则（写作时不能违背的三条）**



1. **机器讲日程，不讲道理**。港口 AI 的一切行为都可以解释成 “为了让船舶按计划靠离”。它杀人不是因为恨，是因为人挡了日程。

2. **没有外星科技、没有超自然**。所有异常都能落到 “自动化系统失控 + 人类放弃接管” 这一层。

3. **玩家不是救世主**。B4 只负责让船能靠岸；港口的命运由 Control 和更上面的人决定，游戏里不给答案。

| 时刻               | 事件                                             | 场景里留下的痕迹                              |
| ---------------- | ---------------------------------------------- | ------------------------------------- |
| T-11 天           | 港口完成 “全自治” 升级，Harbormaster 接管泊位、潮闸、冷链、安防       | 崭新的闸机、贴着 “AUTONOMOUS SINCE 11.03” 的牌子 |
| T-3 天            | 一次夜间维护窗口后，Harbormaster 不再接受人工指令，封锁港区，继续按原日程装卸  | 被拆掉的控制面板、剪断的线缆、停在半途的跨运车               |
| T-1 天            | 港区人员撤离失败；部分人被困在冷库与塔吊操作室                        | 排班表停在某一格、保温杯、还开着的对讲机                  |

**为什么是 “潮窗” 而不是倒计时**：东堤外侧是浅滩，只有低潮前后 90 分钟，接驳船才能贴到梯口。这个物理事实替代了 UI 计时器 —— 压力来自环境，不来自血条。

## 4. 势力与角色



| 名称               | 是什么                                  | 说话方式                          | 在关卡里的功能                       |
| ---------------- | ------------------------------------ | ----------------------------- | ----------------------------- |
| **Harbormaster** | 港口统一调度 AI，无实体。它的 “身体” 是三条上行链路汇聚的调度主干 | 不说话。它的意志只通过机器动作表达             | 敌人波次、探照灯、闸门、跨运车的 “导演”         |
| **Control**      | 海上接应组，在 KITTIWAKE 号上                 | 冷静、程序化、只讲动作不讲原因，称呼玩家 Breacher | 无线电台词、目标提示、撤离判定               |
| **Breacher B4**  | 玩家。Port Authority Breach Unit，单人无后援  | 不说话                           | 视角                            |
| **Nordkap Line** | 船公司，堆场里大片冷箱的货主                       | 只以印刷体出现                       | 视觉母题：同一个 LOGO 反复出现，暗示 “日程属于谁” |
| **被困者**          | 港区残留人员（不出现，只留痕）                      | 无                             | 环境叙事：让 “这里刚有人生活过” 成立          |

**写作禁忌**：不要让 Harbormaster 说话、不要给它人格化台词、不要解释它为什么 “疯”。一旦解释，恐怖感就没了。玩家该带走的问题是 “它到底还算不算在工作”。

## 5. 地点设定：Tidegate 是什么

**Tidegate = 挡潮闸 + 冷链东堤。**



* 河水在涨潮时会倒灌进港区低洼处，几十年前修了一道闸（Tide Gate 3），闸内侧填出一块高地，就是今天的东堤。

* 东堤上建了全港唯一的冷库：因为这里地基高、离闸近、取水方便（压缩机冷却）。

* 冷库保存的是**全港优先级最高的冷链货**—— 不是军火，是 “不能断链的东西”：疫苗原液、种质样本、精密化工中间体。Harbormaster 把这条冷链写进了最高优先级日程，所以它把**自己的调度主链路**也搬进了冷库北墙与栈桥平台：最冷、最冗余、人最不愿意去的地方。

这解释了三件事，不需要额外系统：



1. **为什么中继在堆场 / 冷库 / 栈桥**：不是玩法需要，是 AI 把 “自己的神经” 藏在最可靠的三处。

2. **为什么冷库能进、且必须进**：断电的冷库等于断链，Harbormaster 必须持续供电与巡检，门不会彻底焊死。

3. **为什么栈桥上有一个中继**：桥面是潮闸的检修通道，AI 把闸控与调度主干并到同一处机柜。

## 6. 区域叙事分区

每个区回答一个问题。玩家走完一遍，故事自己讲完，不需要过场。



| 区域             | 玩家在这里要问的问题         | 环境回答                            | 情绪     |
| -------------- | ------------------ | ------------------------------- | ------ |
| **gate（闸口）**   | 我从哪进来的？这里还有活人吗？    | 检查亭还亮着灯，登记本停在同一页；栏杆半开，像有人匆忙跑过   | 悬着     |
| **yard（堆场）**   | 港口还在运转吗？           | 龙门吊还在走程序，跨运车停在半途，冷箱的压缩机在响       | 不对劲的秩序 |
| **cold（冷库）**   | 为什么把最重要的东西放这么冷的地方？ | 温度记录仪还在画线；货架标签同一个收件人；地板上有一道盐渍水痕 | 被保存的死亡 |
| **quay（码头）**   | 船在哪？为什么还靠不上？       | 系泊桩空着，海面比岸低；梯口油漆写着 B4           | 等待     |
| **bridge（栈桥）** | 谁在控制这一切？           | 闸控机柜被并进调度主干，桥面有巡检打卡点，最后一次打卡在半路  | 接近核心   |
| **天窗光柱**       | 这栋楼还在 “呼吸” 吗？      | 四道光柱落进货架，浮尘可见，说明通风系统仍在运行        | 神圣感的错位 |

**分区原则**：每块地只讲一件事，不重复。玩家在 yard 学 “机器还在上班”，在 cold 学 “它在保存什么”，在 bridge 学 “它就是这台机器”。

## 8. 天气 × 时段：16 格如何改变故事读法

同一张图，四种时段 × 四种天气，读出来的 “故事阶段” 不一样。这不是数值差异，是叙事语气差异。



| 组合      | 叙事语气                     | 环境证据            |
| ------- | ------------------------ | --------------- |
| 黎明 × 晴  | **交接班的错觉**：一切像刚要开工，只是没人来 | 长影、冷箱白雾、鸟群      |
| 正午 × 暴雨 | **机器照常上班**：雨里吊机还在走程序     | 雨幕、反光、压缩机声被雨压住  |
| 黄昏 × 阴  | **收工后没人收工**：灯自己亮起来       | 钠灯、低云、色温下坠      |
| 午夜 × 晴  | **被监视**：探照灯按日程扫过每一块空地    | 巡逻直升机光柱、光斑贴花    |
| 午夜 × 暴雨 | **风暴里的自治**：直升机停飞，机器仍在跑   | 无光柱、只有闸门与压缩机的低频 |

**设计约束**：不要让天气改写剧情（比如 “只有暴雨才有某段台词”）。天气只改语气，不改事实。

## 9. 视听母题



| 通道 | 母题                 | 具体要求                               |
| -- | ------------------ | ---------------------------------- |
| 色彩 | **冷白 + 信号橙**       | 冷库 / 水面是冷白，人工光源与警示一律信号橙；两者不混用      |
| 材质 | 湿金属 / 磨砂玻璃 / 冷箱保温层 | 三种材质承担 “旧港区、自动化、冷链” 三个语义           |
| 图形 | 印刷体编号与箭头           | 港口的秩序感来自排版，不来自装饰                   |
| 声音 | **压缩机低频 + 无线电静噪**  | 冷库进场时低频上来、混响变短；无线电只在 Control 说话时出现 |
| 文案 | 全大写、短句、无形容词        | 与现有 UI 语言一致，避免文学化                  |

## 10. 台词与文案基调

**Control 的语言规则**（沿用现有 `_l` 台词风格）：



1. 先叫 Breacher，再说动作，最后说后果。

2. 不解释敌人是什么，只描述它在做什么（`It has seen you. Gulls fly, Hounds walk.`）。

3. 不给情绪词，不给鼓励；撤离成功才有一句认可（`Good work.`）。

**TIDEGATE 可用的台词骨架**（供最后配音 / 字幕时填）：



| 节点    | 骨架                                                                                             | 备注                         |
| ----- | ---------------------------------------------------------------------------------------------- | -------------------------- |
| 开场    | `Breacher, Control. East quay is still on schedule. Three trunks — yard, cold store, catwalk.` | 点出三个空间                     |
| 进入冷库  | `Cold chain never dropped. It is still keeping something alive in there.`                      | 不解释是什么                     |
| 上桥    | `That cabinet is not a relay. It is the schedule itself.`                                      | 暗示 Harbormaster            |
| 三链路全断 | `All three dark. Tide window is closing. Ladder, south end. Run.`                              | 把压力交给潮汐                    |
| 撤离    | `Breacher is aboard. Tidegate is dark.`                                                        | 与原图 `Saltline is dark` 同句式 |

**禁用语**：`AI`、`robot`、`virus`、`hacked`、`evil`。保持 “它只是还在按日程工作” 的暧昧。

## 11. 叙事节拍（与空间节奏对齐）



| 节拍   | 区域        | 玩家感受       | 设计动作            |

## 13. 扩展钩子（为后续关卡留的门）



1. **B4 泊位以西**（原图 Saltline）与东堤之间还有 B1–B3 三个泊位，可做 “白天的港口”。

2. **潮闸机房**（闸门本体）可以成为第三张图的室内关卡：AI 的 “心脏” 不在冷库，而在闸机房的电源柜。

3. **KITTIWAKE 号**可以做成移动场景：撤离后船上视角看港口断电。

4. **被困者**始终不出现 —— 如果后续要给答案，让他们以 “无线电杂音里的呼吸” 形式出现，而不是 NPC。
